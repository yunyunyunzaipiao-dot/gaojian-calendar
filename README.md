# 画稿日历

一个本地 HTML 网页原型，用于手动录入画加和 QQ 稿件，并在月历中查看预计工期和截稿日。无需 GPT、账号或外部接口。

## 本地打开

需要安装 Node.js。进入此文件夹后运行：

```bash
npm run dev
```

打开命令行显示的 `http://localhost:5173`。停止服务时按 `Ctrl+C`。

也可以直接双击 `index.html` 查看；用本地服务打开时，浏览器本地保存更稳定。

如果朋友无法访问你发布的网页，也可以把网页文件打包发给对方。请包含 `index.html`、`styles.css`、`calendar.css`、`editor.css`、`calendar-core.js`、`editor-controls.js`、`attachments.js` 和 `app.js`，并保持在同一个文件夹内。

## 分享到 GitHub Pages

把上述网页文件上传到 GitHub 仓库的根目录。在仓库的 **Settings → Pages** 中选择 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`。发布后得到一个普通网页链接，访问者不需要 GPT。

网页没有外部依赖。浏览器会把每个人录入的稿件保存在各自设备的本地存储中；GitHub 仓库不会自动收到这些稿件。当前版本无法自动在手机和电脑之间同步订单。可以在“所有稿件”中导出 JSON 备份，再在另一台设备导入；导入会替换该设备原有的稿件。清理浏览器数据前请先导出备份。

首次打开会显示虚构的示例稿件。点击“清空示例，开始录单”后即可录入自己的稿件。

## 主要功能

- 月历色带两端的小竖线是拖动手柄。拖左端调整预计开工日，拖右端调整预计完成日；点击中间查看稿件。开始和结束不能互相越过。截稿日单独保存。
- 点击日期后，黑底高亮跟随选中的日期；“今天”回到当天并打开当天安排。
- “近期截稿”列出今天至第 7 天（含今天）的未完成稿件，并按截稿日排序。
- 来源用可复用标签单选，稿件类型标签可多选；支持添加自定义标签。
- 预览面板可直接修改进度、付费类型、金额、类型及日期，修改后即时保存。进度分为灰色未开始、黄色进行中、绿色已完成。
- 详情页默认简洁展示，点击“编辑”展开表单，保存或取消后回到详情。
- 月收入按实际完成月份统计已完成的有偿稿件；缺失完成日期的记录暂不计入。
- 来源和类型统计可切换数量/金额，按截稿月份汇总报价；多类型分别计入，不能将类型金额相加当成总收入。
- “这个月画了多久”支持手动填写小时数，并按实际完成月份累计；不是自动计时，不会拆分跨月耗时。
- 日期按钮打开日历；预计工期依次选择开始日、结束日，再点“确定”，也支持跨月。
- 在参考资料区域粘贴图片，或选择、拖入图片和文件。单个文件最多 20 MB，保存在浏览器本地；点击缩略图可放大。
- JSON 备份包含图片和文件内容；备份导入上限为 100 MB。使用附件时建议通过 `npm run dev` 或正式静态网站打开，以获得稳定的浏览器存储支持。

## 验证

运行 `npm test` 检查重叠分层、跨月日期、七天范围和头尾调整边界。打开网页后，可创建一条跨月稿件，分别拖动两端并查看详情日期；添加图片后刷新，再导出、导入备份，确认附件仍能显示。

## 版本与维护

当前基线：`v0.1.0`（2026-10-26）。本次任务记录与后续更新约定见 [版本记录](docs/RELEASES.md)。实现约束见 [决策记录](docs/decisions.md)。

本仓库仅包含应用代码、文档和虚构测试数据。真实稿件、附件和本地备份不要提交；`.local-data/`、`backups/`、`exports/`、环境配置已忽略。分享前应检查 `git diff --cached --stat` 和实际暂存文件。

内置预览、普通浏览器和不同网址的数据各自独立。发布后的网页需要用户自行导入备份；请勿把备份上传到代码仓库。
