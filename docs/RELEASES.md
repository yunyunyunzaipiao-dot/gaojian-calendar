## v0.1.0 · 2026-10-26

首个 Git 版本基线。为手动接稿提供月历排期、稿件资料与月度汇总，无第三方运行依赖。

### 本次已完成

- 整月视图展示跨天工期色带与独立截稿标记；Grid 分层处理重叠任务，日期数字固定在顶部。
- 工期两端可独立拖动；选中日期高亮、“今天”跳转和未来七天待截稿预览。
- 预览支持即时修改进度、单选付费类型、金额、多类型贴纸、预计工期和截稿日。
- 来源采用可复用单选标签；类型支持多选、自定义添加。进度使用灰、黄、绿三色。
- 稿件详情默认只展示相关信息；可切换编辑，保存或取消，再返回简洁展示；预览和详情均可删除稿件。
- 支持粘贴/上传图片及文件，IndexedDB 保存附件；JSON 导出导入包含附件与标签。
- 月收入按实际完成月份汇总已完成的有偿稿件；来源与类型图表按截稿月份切换数量和报价。
- 绘画耗时手动填写小时数，支持小数；按稿件实际完成月份汇总，显示累计及未记录提示。
- 已完成且实际完成日为空时，以截稿日补填；已有日期保留，没有截稿日则不猜测。

### 数据与发布边界

- Git 只保存源代码、通用文档及虚构测试素材，不包含真实订单、客户文字、附件、导入备份或本地迁移脚本。
- 业务数据保存在各浏览器 localStorage 与 IndexedDB 中；没有账号、服务器同步或远程订单写入。
- 仓库上传不等于网站部署。本版本不自动开启 GitHub Pages。
- 自带示例均为虚构内容，首次使用可清空。用户原有浏览器数据不包含在发布文件中。

### 已验证

- `npm test`：六项日历算法测试，覆盖重叠分层、跨周/月、闰日/年末、七天边界及端点调整。
- JavaScript 语法检查。
- 隔离浏览器验证：预览即时修改、多标签、日期范围、详情编辑/取消/保存、来源复用、数量/金额切换、小时数汇总、刷新持久化、备份恢复及手机布局。
- 隔离验证使用虚构数据，不更改用户当前浏览器订单。

### 已知限制与后续候选

- 暂无自动工时计时、跨设备同步、平台自动录单、价目表或流量统计。
- 手工填写的总小时数按完成月份归属，不能表示分散到不同月份的实际劳动时间。
- 月收入是完成稿件的报价统计，不是实际到账对账；来源/类型金额是截稿月份报价分布。
- 类型字符串的历史兼容分隔符为 ` · `。未来若引入结构化数据，应迁移为数组。

## 后续版本更新流程

1. 从当前 Git 基线新建功能分支，明确本次要改的范围。
2. 只修改相关文件；若变更数据字段，保留旧备份兼容并说明迁移方式。
3. 执行相关测试；在隔离浏览器中验证，不拿真实订单做破坏性测试。
4. 在本文件最前面添加新版本，记录变更、验证和限制；同步 README 与版本号。
5. 提交前核查暂存文件、差异及隐私，禁止提交备份、客户内容和密钥。
6. 创建 Git 提交与版本标签，再推送到已确认的 GitHub 仓库。
